## Open source

### [whatsapp-cloud-api](https://github.com/SolveJet/whatsapp-cloud-api)

[![npm version](https://img.shields.io/npm/v/@solvejet/whatsapp-cloud-api.svg)](https://www.npmjs.com/package/@solvejet/whatsapp-cloud-api)
[![license](https://img.shields.io/npm/l/@solvejet/whatsapp-cloud-api.svg)](https://github.com/SolveJet/whatsapp-cloud-api/blob/master/LICENSE)

A zero-dependency TypeScript SDK for the WhatsApp Cloud API. It covers sending messages, templates, media, webhooks and Flows. Requires Node 20+, MIT licensed, published to npm with provenance.

[Repository](https://github.com/SolveJet/whatsapp-cloud-api) · [npm](https://www.npmjs.com/package/@solvejet/whatsapp-cloud-api) · [Docs](https://solvejet.github.io/whatsapp-cloud-api/) · [Discussions](https://github.com/SolveJet/whatsapp-cloud-api/discussions)

*Independent project, not affiliated with Meta or WhatsApp.*
